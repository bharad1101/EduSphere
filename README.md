# EduSphere

EduSphere is an educational web project containing learning-related pages, student data, and server-side functionality.

## Technologies

- HTML
- CSS
- JavaScript
- TypeScript
- Python
- JSON and XML

## Project Structure

- `index.html` — Main page
- `login.html` — Login page
- `register.html` — Registration page
- `catalogue.html` — Catalogue page
- `style.css` — Stylesheet
- `server.py` — Python server
- `students.json` — Student data
- `week6.html` through `week14/` — Additional project exercises and resources

## Getting Started

1. Clone this repository.
2. Open `index.html` in a browser to view the frontend.
3. If you need server-side functionality, check `server.py` for the required setup and run instructions.
